> إنشاء وتصميم موقع شخصي، ورفع جميع الملفات مع كتابة ملف README على GitHub، ونشره عبر GitHub Pages.

## Features | المميزات

- **Bilingual:** Arabic (RTL) and English (LTR), switched with one button — ثنائي اللغة
- **Dark / Light mode** saved in the browser — الوضع الليلي
- **Responsive design** for mobile, tablet and desktop — متجاوب مع الجوال
- **Typing animation** in the hero section
- **Animated skill bars** and scroll reveal effects
- **Project filter** (All / Robotics)
- **Contact form** with validation that opens the email app (`mailto:`)
- Sticky navbar with active-section highlight and back-to-top button

## Sections | أقسام الموقع

| Section | Content |
|---------|---------|
| Home | Name, title, short intro |
| About | Bio, education, interests |
| Skills | HTML, CSS, JavaScript, Arduino, Git, Simulation |
| Projects | Servo task, walking algorithm |
| Contact | Email, GitHub, contact form |

## Files | الملفات

| File | Description |
|------|-------------|
| `index.html` | Page structure (HTML) |
| `css/style.css` | Design, colors, layout and animations (CSS) |
| `js/script.js` | Language switch, theme, typing, filters, form (JavaScript) |
| `GITHUB_PAGES.md` | Steps to upload to GitHub and publish with GitHub Pages |

## Technologies

- HTML5
- CSS3 (Flexbox, Grid, CSS variables, media queries)
- JavaScript (DOM, events, `localStorage`, `IntersectionObserver`)
- Google Fonts (Cairo, Poppins)

## Run locally | التشغيل محلياً

No installation needed. Open `index.html` in any browser (double-click it),  
or in VS Code use the **Live Server** extension → *Open with Live Server*.

## Publish | النشر

See **GITHUB_PAGES.md**.
